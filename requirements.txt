# DaVinci AutoCut has NO Python package dependencies.
#
# Silence detection is done with ffmpeg's built-in `silencedetect` filter, so
# the only runtime requirements are:
#   * Python 3 (DaVinci Resolve needs it to run Python scripts at all)
#   * ffmpeg   (the installer bundles ffmpeg.exe next to the plugin on Windows)
#
# The GUI uses Tkinter, which ships with the standard Python installers.
#
# This file is intentionally empty of packages -- nothing to `pip install`.
